# ภาษีบ้านฉันไปไหน

[English](README.en.md) · **[เปิดเว็บ](https://nuttakulsv.github.io/thai-local-spend/)** · ทำด้วย [thai-egp](https://github.com/nuttakulsv/thai-egp)

เลือกจังหวัดกับอำเภอ แล้วดูว่าหน่วยงานรัฐในพื้นที่ใช้เงินจ้างอะไร จ้างใคร เท่าไหร่ ไม่ว่าจะเป็น อบต. เทศบาล โรงเรียน หรือโรงพยาบาลอำเภอ ข้อมูลมาจากระบบจัดซื้อจัดจ้างภาครัฐ (e-GP) ของกรมบัญชีกลาง

ในแต่ละอำเภอจะเห็น

- ยอดเงินรวม จำนวนสัญญา และสัดส่วนของแต่ละวิธีจัดซื้อ เช่น e-bidding หรือเฉพาะเจาะจง
- หน่วยงานที่จ้างมากที่สุด และผู้รับจ้างที่ได้เงินมากที่สุด กดชื่อไหนก็กรองรายการตามชื่อนั้น
- รายการสัญญาทั้งหมด ค้นจากชื่อโครงการ หน่วยงาน ผู้รับจ้าง หรือเลขโครงการได้
- แผนที่ของโครงการที่หน่วยงานระบุพิกัดไว้

ลิงก์ของแต่ละหน้าส่งต่อได้เลย เช่น `#เชียงใหม่/แม่ริม`

## อ่านตัวเลขยังไง

- **นับตามที่ตั้งของหน่วยงานที่จ้าง ไม่ใช่ที่ตั้งโครงการ** อบต. กับเทศบาลอยู่ในพื้นที่ของตัวเองอยู่แล้ว แต่ถนนที่กรมทางหลวงจ้างจะไปอยู่ที่ที่ตั้งของแขวงทางหลวง และงานของกระทรวงจะไปอยู่ที่กรุงเทพฯ ยอดของกรุงเทพฯ จึงสูงมาก
- **สัญญาที่ระบบไม่ได้บอกอำเภอ อยู่ใน "ไม่ระบุอำเภอ" ของแต่ละจังหวัด** ข้อมูลปี 2568 ใส่ อ.ตรอน ต.เพ ไว้แทนช่องว่าง เราจึงย้ายแถวพวกนั้นมาไว้ตรงนี้
- **มีเฉพาะสัญญาตั้งแต่ 100,000 บาทขึ้นไป** งานหลักร้อยหลักพันมีเป็นล้านรายการ ถ้าใส่ทั้งหมด เว็บจะช้าเกินไปจนใช้ไม่ได้
- **ผู้รับจ้างที่เป็นบุคคลธรรมดาไม่แสดงชื่อ** ยอดเงินยังนับรวมอยู่ และหน้าเว็บบอกไว้ว่ามีกี่สัญญา ถ้าดูไม่ออกว่าเป็นบริษัทหรือคน เช่น ชื่อภาษาอังกฤษที่ไม่มีคำว่า บริษัท หรือ Co., Ltd. และใช้เลขจากกรมสรรพากร ก็จะไม่แสดงชื่อเหมือนกัน
- **ตัวเลขมาจากที่หน่วยงานกรอกในระบบ** ถ้ากรอกผิด ตัวเลขก็ผิดตาม เลขโครงการ 11 หลักใช้ค้นต่อในระบบ e-GP หรือเว็บ [ภาษีไปไหน](https://govspending.data.go.th) ได้

## สร้างข้อมูลเอง

ต้องมี Python 3.9 ขึ้นไป และ [thai-egp](https://github.com/nuttakulsv/thai-egp)

```
pip install git+https://github.com/nuttakulsv/thai-egp
egp download 2568                        # ไฟล์ดิบทั้งปีราว 5 GB ถ้าเน็ตค้างจะโหลดต่อจากที่ค้างเอง
python3 build.py egp-data/2568/*.csv     # เขียนลง data/ ใช้เวลาไม่กี่นาที
python3 -m http.server                   # เปิด http://localhost:8000
```

สั่ง `python3 build.py 2568` เพื่ออ่านตรงจาก data.go.th โดยไม่เก็บไฟล์ดิบก็ได้ แต่ถ้าเซิร์ฟเวอร์ค้างกลางไฟล์ ต้องอ่านไฟล์นั้นใหม่ตั้งแต่ต้น ไฟล์ที่ได้เป็น JSON หนึ่งไฟล์ต่ออำเภอ ใน `data/` เว็บเป็น HTML ไฟล์เดียว ไม่มีขั้นตอน build ฝั่งหน้าเว็บ ใช้ GitHub Pages ได้เลย

data.go.th ไม่ค่อยตอบเครื่องที่อยู่นอกประเทศไทย จึงยังไม่ได้ตั้ง GitHub Actions ให้อัปเดตเอง ต้องรันจากเครื่องในประเทศไทย

เทสต์: `PYTHONPATH=../thai-egp python3 test/test_build.py` และถ้ามี jsdom `node test/page.test.js .`

## ที่มาของข้อมูล

ข้อมูลจัดซื้อจัดจ้างจากระบบ e-GP ของกรมบัญชีกลาง เผยแพร่โดยสำนักงานพัฒนารัฐบาลดิจิทัล (องค์การมหาชน) บน [data.go.th](https://data.go.th) ภายใต้สัญญาอนุญาต Creative Commons Attribution แผนที่จาก OpenStreetMap
